# Extensions Inkora

Catalogue lu par l'application : `index.json`, SushiScan et MangaDex.

Adresse : https://github.com/Octane-XT/inkora-extensions/tree/main

Les fichiers sont à la racine. L'application les télécharge sans token. Une version plus récente est proposée dans Paramètres, puis installée seulement après accord.

`hosts` déclare les domaines qui ne sont pas des sous-domaines de `baseUrl` (CDN, autre API). Le domaine de `baseUrl` et ses sous-domaines sont déjà autorisés.
